# BU CS Foundations Bootcamp
 
This repository contains my work for the Boston University
Online AI Programs CS Foundations Bootcamp.
 
## Structure
- bu-bootcamp
- module1/ : Development environment and first Java programs
    -- several code examples for practice on the first day of online AI program
- module2_javacourse/ : Programming fundamentals (variables, control flow, methods, files)
    -- several programs and practice on BufferedWriter & BufferedReader - FileWriter and FileReader.
- module3/ : Data structures and object-oriented basics
    -- several code examples on arraylist for practice and hashmaps. 
- GradeAnayzer 
- notes
    -- show screens shots to remember code fundamentals.

 
## Programs
Each module folder contains the Java source files from that module’s activity and practice codes and GradeAnalyzer is separate.
